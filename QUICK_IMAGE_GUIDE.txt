TROUBLESHOOTING:
================

Image dimensions wrong?
  → Use free online tool: https://resizr.app/
  → Or use image editor (Photoshop, GIMP, Paint.net)
  → Must be EXACT size (e.g., 1200x630, not 1200x632)

File won't load in browser?
  → Check file is in correct folder: static/images/
  → Check file name matches exactly: og-image.png (not og_image or ogimage)
  → Hard refresh browser (Ctrl+F5)
  → Check for typos in file paths

Icon not appearing in browser tab?
  → Make sure favicon.png is exactly 512x512px
  → Hard refresh (Ctrl+F5 or Cmd+Shift+R)
  → Try a different browser
  → Clear browser cache

Image looks blurry on mobile?
  → Check file size and quality
  → Use TinyPNG.com to compress while maintaining quality
  → Ensure it's high resolution (PNG is better than JPG)

File size too large?
  → Use TinyPNG.com to compress
  → Use ImageOptim (Mac) or similar
  → Must be: OG under 500KB, Favicon/Icon under 100KB each
