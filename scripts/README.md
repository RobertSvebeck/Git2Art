# Scripts Archive

This folder contains previous versions and experimental scripts from the Git2Art development process.

## Files

### Development Versions

- **`git2art_v1_simple.py`** - Initial simple implementation with basic grid layout and random colors
- **`git2art_v2.py`** - Art theory enhanced version (golden ratio, color harmony, first iteration)
- **`git2art_v2_muted.py`** - Muted color palette version before organic enhancement
- **`git2art_organic.py`** - First organic/vibrant version with high saturation
- **`git2art_vibrant_v1.py`** - Vibrant version before harmonious palettes

### Examples

- **`example.py`** - Simple example Python file with test functions (used for testing the art generator)

### Test Images (Development Journey)

- **`git2art_initial.png`** - Very first generation (empty repo)

## Current Version

The current production version is in the root directory: `git2art.py`

This version includes:
- Repository-driven harmonious color palettes
- IDEO-inspired Cornu curves and rich texture
- Bold, thick strokes (up to 30% of canvas width)
- Filled color areas and mixed colors
- All art theory principles combined

## Why These Are Archived

These files represent the iterative development journey documented in `CLAUDE.md`. They are kept for:
- Historical reference
- Educational purposes
- Comparing approaches
- Potential feature extraction

They are not intended for production use.
