## Usage in HTML (Already Configured)

The favicon and touch icon are already referenced in your `templates/base.html`:

```html
<!-- Favicon -->
<link rel="icon" type="image/png" href="{{ url_for('static', filename='images/favicon.png') }}">
<link rel="apple-touch-icon" href="{{ url_for('static', filename='images/apple-touch-icon.png') }}">
```

The OG image is referenced in meta tags:
```html
<meta property="og:image" content="https://git2art.com/static/images/og-image.png">
```

**Just add your images to these locations:**
- `static/images/og-image.png`
- `static/images/favicon.png`
- `static/images/apple-touch-icon.png`

## Testing Your Images

### After Saving Files:

1. **Test OG Image on Social Media:**
   ```
   Tool: Twitter Card Validator
   URL: https://cards-dev.twitter.com/validator
   Test: https://git2art.com
   ```

2. **Test Favicon in Browser:**
   ```
   Action: Hard refresh (Ctrl+F5 or Cmd+Shift+R)
   Check: Browser tab shows favicon
   Check: Bookmark shows icon
   ```

3. **Test on Mobile:**
   ```
   iOS: Add web clip to home screen
   Check: Appears with correct icon

   Android: Add bookmark to home screen
   Check: Appears with correct icon
   ```

4. **Validate Image Dimensions:**
   ```
   On Mac: Select file → Get Info → Dimensions
   On Windows: Right-click → Properties → Details
   Online: https://resizr.app/ or similar tool
   ```

## Pro Tips

1. **Keep text readable** - Make sure "Git2Art" is clearly visible in OG image
2. **Use high contrast** - Light text on dark background or vice versa
3. **Avoid centered text** - Slightly off-center looks more professional
4. **Include motion** - Design should feel dynamic, not static
5. **Test extensively** - Check across different platforms and devices
6. **Consider dark mode** - Ensure favicon works on dark theme browsers
7. **Compress before using** - Use TinyPNG.com or similar to reduce file size
8. **Keep it simple** - Favicon must work at tiny sizes, so avoid complexity
