# Art Theory in Git2Art

Git2Art v2 incorporates established principles of abstract art and visual design to create aesthetically pleasing compositions.

## Color Theory

### Color Harmonies

The generator uses three scientifically-proven color schemes based on color wheel relationships:

#### 1. **Complementary Palette** (1-3 files)
- Uses colors opposite on the color wheel (180° apart)
- Creates high contrast and visual impact
- Perfect for small, focused compositions
- Example: Blue ↔ Orange, Red ↔ Green

#### 2. **Triadic Palette** (4-10 files)
- Three colors evenly spaced around color wheel (120° apart)
- Balanced, vibrant, harmonious
- Provides variety while maintaining unity
- Example: Red, Yellow, Blue

#### 3. **Analogous Palette** (11+ files)
- Colors adjacent on color wheel (within 30°)
- Peaceful, comfortable, cohesive
- Works well for complex compositions
- Example: Blue, Blue-Green, Green, Yellow-Green

### Why Color Harmony Matters
- **Unity**: Related colors create visual coherence
- **Mood**: Harmonious colors are easier on the eyes
- **Professional**: Follows centuries of art tradition
- **Meaning**: Color relationships communicate balance

## Composition Principles

### Golden Ratio (φ ≈ 1.618)
- Mathematical ratio found throughout nature and art
- Used to place focal points at visually pleasing positions
- Creates natural balance that feels "right" to viewers
- Applied to element positioning and background gradients

### Rule of Thirds
- Divides canvas into 9 equal parts (3×3 grid)
- Important elements placed at intersection points
- More dynamic than pure center composition
- Used in photography, painting, and design

### Fibonacci Spiral
- Natural spiral based on golden ratio growth
- Used for element flow and secondary positioning
- Creates movement and visual journey through the piece
- Guides viewer's eye through the composition

## Visual Hierarchy

### Size = Importance
- Larger files (more lines of code) = Larger visual elements
- Creates clear focal points
- Helps viewer understand relative importance
- Prevents visual chaos

### Shape Variation by File Type
- **Python files (.py)**: Organic circles (fluid, dynamic)
- **Markdown files (.md)**: Rounded rectangles (structured, readable)
- **Text files (.txt)**: Triangles (sharp, simple)
- **Other files**: Hexagons (unique, technical)

### Opacity Variations
- More important files: Higher opacity (more solid)
- Less important files: Lower opacity (more ethereal)
- Creates depth and layering
- Prevents overcrowding

## Flow and Unity

### Connecting Flow Lines
- Subtle curves connect related elements
- Creates visual pathways
- Suggests relationships between files
- Uses Bézier curves for smooth, organic feel

### Background Gradient
- Multi-center gradient based on golden ratio points
- Unifies the composition
- Provides subtle depth
- Uses palette colors for harmony

### Texture and Depth
- Subtle gaussian blur for atmospheric effect
- Prevents harsh, digital appearance
- Adds sophistication
- Creates layered visual experience

## Contrast and Balance

### Contrast Creates Interest
- Size variation (large vs small)
- Opacity variation (solid vs transparent)
- Color variation (within harmonious palette)
- Shape variation (different file types)

### Balance Prevents Chaos
- Symmetrical distribution of visual weight
- No single area too dense or too sparse
- Balanced color distribution
- Equal attention to negative space

## Why These Principles Work

### Psychological Basis
- **Gestalt Theory**: Humans perceive organized patterns
- **Color Psychology**: Harmonious colors reduce cognitive load
- **Natural Patterns**: Golden ratio appears in nature (shells, galaxies)
- **Cultural Learning**: Centuries of art tradition

### Mathematical Foundation
- **Golden Ratio**: irrational number φ = (1 + √5) / 2
- **Color Theory**: Based on light wavelength relationships
- **Geometric Balance**: Symmetry and proportion
- **Fibonacci Sequence**: 0, 1, 1, 2, 3, 5, 8, 13...

## Determinism in Art

Despite using sophisticated principles, Git2Art remains **100% deterministic**:

- Same repository state → Same art (always)
- Small code changes → Small visual changes
- Large code changes → Large visual changes
- Hash-based color selection within palette
- Predictable layout algorithms
